# Farm System 보안/웹 7회차 — 실습 챌린지 3종

"0810_Farm_여름방학_7회차.pdf" (보안의 전체 흐름: 암호학에서 AI 보안까지) 강의를
30분 실습으로 옮긴 것입니다. 세 개 다 만들어뒀고, 실제 수업에는 그 중 **하나만** 골라
쓰면 됩니다. 각 폴더의 README.md에 진행 순서와 힌트가 단계별로 정리되어 있습니다.

| 폴더 | 주제 | 난이도 | 추천 대상 |
|---|---|---|---|
| `01_sql_injection` | SQL Injection 로그인 우회 | 쉬움 | 전체 |
| `02_idor` | 인가 누락 (IDOR) | 제일 쉬움 | 전체, 입문자도 가능 |
| `03_rsa_break` | RSA 암호 깨기 | 어려움 | 파이썬 문법 아는 학생 |

## 힌트 방식 (webhacking.kr 스타일)

정답을 바로 알려주지 않고, 세 단계로 힌트를 숨겨뒀습니다.

1. **페이지 소스보기(Ctrl+U 또는 우클릭 → 페이지 소스)** 하면 HTML 주석으로 힌트가 있습니다.
2. 각 폴더 README.md에는 `<details>` 접이식 힌트가 순서대로 있어서, 막히는 시점마다
   하나씩 펼쳐서 보여주면 됩니다.
3. 맨 아래 "정답"은 정말 안 풀릴 때만 여는 최후의 수단입니다.

수업 흐름 추천: **소스코드(app.py)는 공격 단계에서는 보여주지 말고**, 다 풀고 난
다음("왜 뚫리는지" 설명 단계)에 같이 열어서 코드로 확인시켜주세요. 그래야 "찾아내는
재미"가 삽니다.

## 실행하는 법 (더블클릭 한 번)

### 하나만 켜기
각 폴더 안에 `run.command`가 있습니다. **파이썬 3만 설치되어 있으면** 더블클릭 한 번으로
- Flask 라이브러리를 자동 설치하고 (`pip install -r requirements.txt`, 이미 있으면 그냥 넘어감)
- 서버를 켜고
- 1초 뒤 기본 브라우저로 해당 페이지를 자동으로 엽니다.

macOS에서 처음 더블클릭하면 "확인되지 않은 개발자" 경고가 뜰 수 있는데, `run.command`를
우클릭 → 열기로 한 번 실행하면 이후엔 그냥 더블클릭해도 됩니다.

### 세 개 다 한 번에 켜기
최상위 폴더의 `run_all.command`를 더블클릭하면 세 챌린지에 필요한 라이브러리를
전부 설치하고, 세 서버(5001/5002/5003)를 동시에 켜고, 브라우저 탭 3개를 자동으로
엽니다. 끝내려면 그 터미널 창에서 Ctrl+C 한 번(또는 창 닫기) — 세 서버가 같이
종료됩니다. 어떤 챌린지를 고를지 아직 안 정했을 때, 또는 선생님이 미리보기용으로
셋 다 켜둘 때 편합니다.

터미널에서 직접 실행하고 싶다면:

```bash
cd 01_sql_injection && python3 app.py   # :5001
cd 02_idor          && python3 app.py   # :5002
cd 03_rsa_break      && python3 app.py   # :5003
```

셋 다 SQLite 파일을 새로 만들며 시작하므로(별도 DB 설치 불필요, 파이썬 내장 모듈만 사용),
여러 번 재시작해도 항상 같은 초기 상태로 돌아갑니다. **주의**: 서버가 켜져 있는 동안
`.db` 파일을 손으로 지우지 마세요 — 지우면 빈 파일이 새로 생겨서 "no such table" 에러가
납니다. DB를 초기화하고 싶으면 서버를 끈 다음에 지우고 다시 켜세요.

### 파이썬조차 없는 학생이 있다면
- **같은 와이파이에 있다면**: 선생님 노트북 한 대에서만 서버를 켜고(`app.run()`의
  host를 `0.0.0.0`으로 바꿔야 함), 학생들은 각자 브라우저로 `http://선생님IP:5001`
  처럼 접속하면 됩니다. 설치가 아예 필요 없는 가장 간단한 방법입니다.
- **완전 독립 실행파일(PyInstaller)**: 라이브러리는 물론 파이썬 자체도 필요 없게
  만들 수 있지만, 빌드한 컴퓨터의 OS에서만 동작합니다(Mac에서 빌드하면 Mac용만).
  학생들 컴퓨터가 전부 같은 OS가 아니라면 OS별로 따로 빌드해야 해서, 학생 컴퓨터가
  섞여있다면 위 와이파이 공유 방식이 더 현실적입니다.
