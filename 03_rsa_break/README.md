# RSA 깨기 실습 (약 30분, Python 문법 아는 학생 대상)

슬라이드 11 "공개키 암호"에 나온 바로 그 문제(`3233 = ? × ?`)를 실제로 풀어서
암호문을 복호화하는 챌린지입니다. 다른 두 챌린지와 달리 "취약한 웹앱을 패치"하는
구조가 아니라, "작은 키로 만든 RSA를 직접 깨보는" 공격 전용 챌린지입니다.
(패치는 코드가 아니라 개념으로 — "키를 크게 만든다" — 마무리에서 설명합니다.)

이 챌린지는 SQLi/IDOR보다 수학적 사고가 더 필요합니다. **파이썬 반복문·모듈러 연산에
익숙한 학생** (엄제윤 Python, 이수성 AI, 빌리 파이썬→해킹/보안 등)에게 추천합니다.
KSEF Junior처럼 막 코딩을 시작한 학생에게는 시간이 촉박할 수 있습니다.

## 준비 (2분)

```bash
cd 03_rsa_break

python app.py
```

브라우저에서 http://127.0.0.1:5003 접속. 공개키(n, e)와 암호화된 메시지가 보입니다.

## 진행 순서

### 1. 문제 소개 (3분)
"이 화면에 있는 n, e만 가지고 암호문을 읽을 수 있을까?"로 시작합니다.
슬라이드 11의 `3233 = ? × ?` 문제를 다시 보여주면서 "지금 그 숫자로 실제 문제를
풀어볼 것"이라고 연결합니다.

### 2. 공격 — 학생 스스로 풀어보기 (15분)
막히는 지점마다 순서대로 힌트를 공개합니다. (페이지 소스보기를 하면 힌트가 전부
HTML 주석으로 이미 적혀 있습니다.)

<details>
<summary>힌트 1 — 왜 작은 n이 위험한가</summary>

n = p × q 입니다. 진짜 RSA는 p, q가 수백 자리 숫자라 소인수분해가 사실상 불가능하지만,
지금 n은 3233밖에 안 됩니다. 컴퓨터로 직접 나눠보면 어떨까요?
</details>

<details>
<summary>힌트 2 — p, q 찾기 (파이썬 코드)</summary>

```python
n = 3233
for p in range(2, n):
    if n % p == 0:
        print(p, n // p)
        break
```
</details>

<details>
<summary>힌트 3 — 개인키 d 구하기</summary>

p, q를 구했다면:

```python
phi = (p - 1) * (q - 1)
d = pow(e, -1, phi)   # 파이썬 3.8+ 는 이 한 줄로 모듈러 역원을 구할 수 있습니다
```

(e 값은 화면에 표시된 공개키의 e를 그대로 씁니다.)
</details>

<details>
<summary>힌트 4 — 복호화</summary>

암호문은 문자 하나당 숫자 하나(블록)로 나뉘어 있습니다. 각 블록에
`pow(블록, d, n)` 을 하면 원래 글자의 아스키 코드가 나옵니다. 하지만 이 챌린지
화면에서는 **d 값만 입력하면 서버가 대신 복호화해서 보여줍니다** — d를 구하는
것까지만 직접 하면 됩니다.
</details>

<details>
<summary>정답 (최후의 수단)</summary>

- p = 61, q = 53 (61 × 53 = 3233, 슬라이드 11 그 숫자입니다)
- φ(n) = 60 × 52 = 3120
- d = pow(e, -1, 3120)

이 d를 화면의 "구한 개인키 d" 칸에 입력하면 플래그가 나옵니다.
</details>

### 3. 다 같이 정리 (5분)
`app.py`를 열어서 `P = 61`, `Q = 53` 처럼 진짜 값이 코드에 그대로 있다는 것을 보여줍니다.

슬라이드 16의 "계산 복잡도라는 토대"와 연결하며 마무리합니다. (원한다면 슬라이드 42
"양자컴퓨터와 PQC"까지 짧게 언급해도 좋습니다 — 양자컴퓨터가 등장하면 이 가정 자체가
흔들린다는 이야기입니다.)
